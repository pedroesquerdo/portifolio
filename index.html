SOBRE O PORTFÓLIO

Aprender tecnologia construindo.

Os projetos deste portfólio partem de conceitos de engenharia de software e evoluem de forma incremental. A ideia não é apenas demonstrar uma aplicação pronta, mas registrar o caminho entre uma implementação simples e uma arquitetura mais robusta.

Cada projeto busca responder perguntas práticas: por que filas existem? Quando o processamento deve ser assíncrono? Como mensagens falham? Onde criptografia entra em um sistema? O que uma blockchain realmente resolve?

EM DESENVOLVIMENTO Mensageria

Carteiro

Projeto de estudo progressivo sobre envio de e-mails e mensageria. Começou com envio direto via SMTP e evoluiu para uma API HTTP síncrona em ASP.NET Core. As próximas etapas introduzem persistência, processamento assíncrono, RabbitMQ, ACK/NACK, retries, Dead Letter Queue e idempotência.
